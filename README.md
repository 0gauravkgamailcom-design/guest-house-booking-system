King Sukh Guest House

A Guest House Booking Management System developed using PHP and MySQL.

## Project Features

- Guest House Homepage
- Facilities Section
- Online Booking Form
- Booking Database
- Booking Success Page
- Form Validation
- Mobile Responsive Design
- Secure Admin Login
- Admin Dashboard
- Booking Statistics
- Search and Filter Bookings
- View Booking Details
- Confirm Booking
- Cancel Booking
- Delete Booking
- Admin Logout
- Session Protection

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- phpMyAdmin
- XAMPP
